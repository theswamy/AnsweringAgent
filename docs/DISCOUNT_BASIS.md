# The 35% discount: which NAV it is measured against

SB2 / NLP secondary · 10% of the cheque into Mauritius · generated from `deal_agent`

The discount has to be applied to something. The LPs are the sellers and the GP is
untouched, so the operative denominator is **the LP's share of NAV** — $257.25M, being 98%
of the $35M still to be returned plus Class B's 68.60% of the $325M of profit. Measured
against the fund's whole $360M NAV the same 35% is a larger number, because that pool
includes the GP's carry-bearing share.

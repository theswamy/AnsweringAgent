At each exit

  1. The buyer pays 12.6% of the proceeds to NLPI and 87.4% to SB2.
  2. SB2's receipts pay the NLPF liquidation preference until $30.59M has been paid.
  3. Thereafter SB2's receipts are distributed: Class A 35.93%, Class B1 62.36%, Class B2 1.72%.
  4. SB2 and NLP sell pro-rata, whether the exit is a secondary, an IPO, or post-IPO.

The 12.6% in step 1 is x2; the 87.4% is the balance SB2 retains. Steps 1 and 2 together return NLP $35M, at which point step 3 begins. In absolute terms step 3 is the 31.4 / 54.5 / 14.1 split above.
